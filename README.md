# aydinkalantar.com

A static, single-page site built with HTML and Tailwind CSS (compiled, no CDN runtime). Everything that goes live is in `public/`.

## Deploy to Cloudflare Pages

**Option A: direct upload (no build)**
1. Cloudflare dashboard → Workers & Pages → Create → Pages → Upload assets.
2. Upload `aydinkalantar-homepage.zip` (or drag in the `public/` folder).
3. Under Custom domains, add `aydinkalantar.com` and `www.aydinkalantar.com`.

**Option B: from a Git repo**
- Build command: `npm run build`
- Build output directory: `public`

## Pages

| URL | Source |
| --- | --- |
| `/` | `src/pages/index.html` |
| `/portfolio/` | `src/pages/portfolio.html` |
| `/case-studies/` | `src/pages/case-studies/index.html` |
| `/case-studies/virtual-fashion/` etc. | `src/pages/case-studies/<slug>.html` |
| `/about/` | `src/pages/about.html` |
| `/services/` and `/services/<slug>/` | generated by `src/gen_services.py` |

The header, contact section and footer are shared in `src/partials/layout.html`. The sunburst and project schematics are partials included with `{{> name class="..."}}`.

## Edit
- Edit pages in `src/pages/` and shared parts in `src/partials/`, never the generated HTML in `public/`.
- Colors, fonts and spacing: `tailwind.config.js` and the `:root` variables in `src/input.css`.
- Run `npm install` once, then `npm run build`. It assembles the pages into `public/` and compiles `public/assets/styles.css`.

## Adding your images
- Artwork: put photos in `public/assets/art/` and copy a `<figure>` in the Selected pieces grid of `src/pages/portfolio.html`. Crops used so far are 648x810 (4:5).
- Project screenshots: put them in `public/assets/work/` and swap the schematic in each case study (search `PROJECT IMAGE SLOT`).
- Case study metrics: search `ADD METRICS` in `src/pages/case-studies/`.
- Case study pages are generated by `src/gen_case_studies.py` (run with python3 after editing its text, then `npm run build`). Edit the script, not the generated files, or your edits will be overwritten next time it runs.
- Videos: compress to 1280px wide H.264 with faststart (e.g. `ffmpeg -i in.mp4 -vf scale=1280:-2 -crf 27 -movflags +faststart out.mp4`). Chapter buttons use `data-target="<video id>" data-seek="<seconds>"`.

- Service pages (copy, FAQs, service area and their structured data) are generated by `src/gen_services.py`. Edit the script, run it with python3, then `npm run build`. Keep `public/llms.txt` and the `ProfessionalService` block in `src/partials/layout.html` in step with it.

## Design system

Defined in `tailwind.config.js` (tokens) and `src/input.css` (CSS variables in `:root` plus component classes). Change a color or font once in `:root` and the whole site follows.

| Token | Value | Use |
| --- | --- | --- |
| `canvas` | #FAFAF7 | Page background |
| `ink` | #1A1A18 | Headings, primary button, dark sections |
| `slate-soft` | #44443F | Body text |
| `ink-soft` | #5C5C57 | Labels, metadata |
| `line` | #E5E5DF | All borders (1px only) |
| `accent` | #A65B32 | Hover, focus, active and selection states only |

Type: headings use Space Grotesk 700 with `tracking-tight`; body and UI text use Inter with `leading-relaxed` in `slate-soft`.

Classes: `container-site`, `section`, `grid-asym` (12-column asymmetric grid), `hairline-grid` (cells share one 1px rule), `heading`, `display-xl/lg/md`, `body`, `lede`, `label`, `meta`, `link`, `nav-link`, `btn-primary`, `btn-secondary`, `btn-inverse`, `card`, `card-title`, `tag`, `frame` + `frame-marks` (hairline image frame with corner marks), `surface-ink`, `blueprint`.

Shadows are disabled in the theme on purpose; use 1px `border-line` instead.
